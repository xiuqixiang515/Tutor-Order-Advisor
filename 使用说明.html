01它是怎么工作的

整个工具由三个文件组成，都在同一个文件夹里（仓库里还带了 README、测试和其他文档，不影响运行）：

文件作用
启动监听.bat双击它就能跑起来，会自动找电脑上的 Python
clip_watch.py后台程序，每 0.4 秒看一眼剪贴板有没有新内容
index.html页面本体，所有分析都在这里完成
config.example.jsonAI 与高德的配置模板，不用就放着别管

流程是这样的：你在微信里复制一条单子 → 后台程序发现剪贴板变了 → 判断这像不像家教需求 → 像的话推给页面 → 页面拿它跟你的条件逐项比对 → 出结果。

关键理解
工具不会去读微信。它读的是你的剪贴板——你复制了什么，它才看到什么。这是它能做到零风险的原因，也是它唯一的边界。

02装之前先确认两件事

第一件：电脑上有 Python 3

不确定的话，按 Win + R，输入 cmd 回车，在黑窗口里敲 python --version。

  • 显示 Python 3.x.x → 有了，跳过这步。
  • 提示“不是内部或外部命令” → 没装。去 python.org 下载安装，安装时务必勾上 “Add Python to PATH”，否则启动脚本找不到。

如果你装过 Anaconda，那已经自带 Python，不用再装。启动脚本会优先用它。

第二件：把文件夹放在固定位置

代码从 GitHub 拿：不想装 git 就下载 ZIP 解压，装了 git 就 git clone https://github.com/xiuqixiang515/Tutor-Order-Advisor.git。解压出来的文件夹名会带 -main 后缀，不影响使用。

别放在下载目录或临时文件夹里。建议放 D:\接单工具\ 这种路径简单的地方。路径里最好不要有空格和特殊符号，避免启动脚本出问题。

03安装与启动

  1. 双击 启动监听.bat。
  2. 会弹出一个黑色的命令行窗口，显示「接单监听 已启动」和一行地址，类似 http://127.0.0.1:8791。
  3. 浏览器会自动打开这个地址。页面顶部出现一条绿色的「监听中」，前面有个闪动的小圆点，说明连上了。
  4. 把这个浏览器窗口拖到屏幕一侧，宽度缩到一半左右也行，内容会自动适应。
那个黑色窗口别关
它是程序本体。关掉监听就停了，页面上的绿条会变成红色提示断开。想停止用 Ctrl + C，或者直接关窗口。

04日常怎么用

基本流程

在微信里长按那条家教消息，选「复制」。页面会在半秒内自己跳出结果，不需要你切回去点任何东西。

一次复制多条

微信里可以多选消息后一起复制，粘进去之后会逐条拆开分析，按匹配度从高到低排序。

规则怎么拆

先找每条单子的起头行——就是编号或机构代码那一行。群里的单子几乎都是多行的（【地址】【时间】【要求】各占一行），所以不能按行切，只能按起头切。目前认得这几种：

  • #1051、#1088 —— 井号加数字
  • 【编号】13205、编号：GZ6102226、【单号】
  • XMY-102201、ZX2130、DD2007 —— 字母加数字的机构代码
  • 广州BY26102206、佛山26102202C、深圳线下26050501 —— 城市加日期码
  • 🎃🎃佛山26102202C —— 表情开头的
  • 家教宝贝粥粥: gz10221626 —— 中介名字加 gz 单号

单子之间那些 ———————、**** 之类的分隔线也会当成断点。同一单被转发两次只算一条（比如同一编号出现两遍，只留一条）。

如果单子没有编号、也没有分隔线，只是每行都把年级科目和价格写全了，那就按行拆——两种写法都支持。

默认是 AI 拆单，规则退成兜底

规则终究是「记住几种写法」，遇到没见过的新格式就切不开——整段被当成一条，后面的科目、年级、价格也跟着丢。所以现在默认每次都由 AI 来判断边界，规则只在 AI 没配上的时候兜底。

AI 一次干两件事：

  1. 判断「哪一行是新单子的开头」——只报行号，不动原文一个字
  2. 把每条单子的字段读出来——年级、科目、时薪、每周次数、每次时长、上课日、老师性别、地点、结算方式

第一件事的克制是必要的：让模型把几千字抄一遍，漏一个字、改一个标点，后面的字段解析就跟着错。报行号则完全绕开这个问题——原文由页面按行号从你粘贴的文本里切，一个字都不经模型的手，模型只做判断，不做搬运。

第二件事是这次新加的。规则认不出的写法它也能读：「时薪两百」这种中文数字价格、「92 以上」这种学历黑话、「一周来两回」这种频次说法，规则一个都对不上。AI 读出的字段有值就会覆盖规则的，null 不动。

三道保险兜着，不让它乱来：

  • temperature 设成 0，同样的输入给同样的输出
  • 提示词里写明「消息里没说的就填 null，不要推测、不要补全、不要编」
  • 每个字段都做类型和范围校验：时薪 1–5000、每周次数 1–14、每次时长 0.25–12 小时、科目必须在白名单里、星期必须是 0–6。orders 和行号长度对不上就整体作废——错位的话会把 A 单的年级安到 B 单头上，比不补更糟

哪些字段是 AI 读的，列表和详情页都会标出来（「这条的 年级、时薪、每周次数… 是 AI 读出来的」）。读错了你得知道该回去核原文哪一行。

AI 没配上的时候自动走规则，并且会提示你「这段有点长，AI 没配，先用规则切成 N 条」。

以前还会拿「AI 切出的条数不到规则一半」当不信任的理由，那个判断去掉了——那是拿规则当基准，而规则恰恰是会切错的那个。现在只防一种情况：切出来的条数接近总行数（那是把单子拆碎了）。

排序之后点任意一条，可以看它的详细分析。

它不会乱跳

复制普通文字（比如一段聊天、一个链接、一句工作安排），页面不会反应。只有同时满足三个条件才算家教单：长度够、命中两个以上特征词（年级、科目、老师、课时等）、并且带价格线索（元、块、课时费、时薪）。

手动模式

如果只是想临时算一单，不用开监听。直接双击 index.html 用浏览器打开，把内容粘进输入框，点「分析输入框里的内容」就行。也可以点「从剪贴板读取并分析」，一键读当前剪贴板。

通勤那一块怎么看

这里的数字有两种来源，标签会直接告诉你：

标签含义
公交 / 步行 / 驾车高德真查过的。下面会写清楚坐几号线、换乘几次、步行多少米，以及目的地被识别成了哪个地方
估算按你在「设条件」里填的片区时间算的，没查具体路线
未知地点认出来了，但这个片区你没填过通勤时间，只能按你设的上限兜底

比例条绿色是上课时间，橙色是路上时间。橙色比绿色还长的时候，这单基本要重新算账——每周跑两次、每次路上一个半小时，等于白干一天。

要看到「坐地铁几号线」这种真实路线，得在「设条件 → 接口配置」里填高德 Key（申请方法见第 07 章）。没填也能用，只是距离按你手填的片区时间估。

为什么列表里的分和点开后的不一样

通勤是要花钱查的。为了不把你每天的免费额度烧光，页面不会一粘贴就去查——列表先按「你能接受的通勤上限」估一个值，只有点开某一条，才真去查那一单。

于是会有这个现象：列表里 79 分，点开变成 75 分，因为真实通勤比假设的远。

列表右上角有个「算全部通勤（N 条）」的绿色链接，点一下就把还没查过的全算完，查完统一重排。这样列表和点开后的分数就一致了。

做法代价与效果
不点零消耗，但分数是按上限估的。带「距离待查」标签的就是这种
点开单条只查这一条，其他条还是估的
算全部通勤一次查完再重排，分数最准。走的是地理编码，5000 次/日，不像 POI 搜索只有 100 次/日
最该看的是净时薪
「200 元一小时」听起来不错，但如果单程 40 分钟、每周两次，扣掉路上时间和车费，实际净时薪可能只有 115。这个数字才是你真正在赚的钱，也是这个工具存在的意义。
别被「没识别出来」的中性分骗了
单子里某个字段没解析出来时，那一项会给一个中间分（比如年级给 55、距离给 45），不代表这单真的合适。看到「单子没写年级」「地点还没配通勤时间」这类说明，先去核对单子原文，别直接信总分。

第一次用之前记得点右上角「设条件」，把你的科目、年级、常去区域和通勤时间、净时薪底线填一遍。这些存在浏览器本地，填一次就够了。

区域那条最关键，格式是 海淀:25, 朝阳:45，直接决定距离这一项算得准不准。没配的区域会被标成「距离未知」。

06开启 AI 拆单（可选）

规则只认常见写法。有些单子写得很随意，比如「孩子高二数学老是七十多分，一周来两次，价格好商量」——「来两次」这种说法规则认不出频次，单次时长和价格干脆没写。拆单和读字段现在都由 AI 负责，这些写法它能读出来。

它是怎么工作的

规则先跑，一秒内出结果，该显示的立刻显示。同时在后台问一次 AI，拿到后按行号重新切分、把字段覆盖上去，再重算匹配度。所以速度不受影响，AI 只做判断和读取，不改你粘贴的原文。

一次调用干两件事：

  1. 判断「哪一行是一条新单子的开头」——只报行号，不让它复述原文。让模型把几千字抄一遍，漏一个字、改一个标点，后面的字段解析就跟着错；报行号则完全绕开这个问题，原文由页面按行号从你粘贴的文本里切，一个字都不经模型的手
  2. 把每条单子的字段读出来——年级、科目、时薪、每周次数、每次时长、上课日、老师性别、地点、结算方式。有值就覆盖规则的，null 不动。规则认错的字段靠这个纠回来

三道保险兜着，不让它乱来：

  • temperature 设成 0，同样的输入给同样的输出
  • 提示词里写明「消息里没说的就填 null，不要推测、不要补全、不要编」
  • 每个字段都做类型和范围校验：时薪 1–5000、每周次数 1–14、每次时长 0.25–12 小时、科目必须在白名单里、星期必须是 0–6。orders 和行号长度对不上就整体作废——错位的话会把 A 单的年级安到 B 单头上，比不补更糟

哪些字段是 AI 读的，列表和详情页都会标出来（「这条的 年级、时薪、每周次数… 是 AI 读出来的」）。读错了你得知道该回去核原文哪一行。

AI 没配上的时候自动走规则，并且会提示你「这段有点长，AI 没配，先用规则切成 N 条」。

怎么配

推荐在页面上填，不用碰任何文件：点右上角「设条件」，拉到最下面的「接口配置」，填 AI 接口地址、API Key、模型名三项，收起面板就生效。

  1. 去模型厂商那边申请一个 API Key，DeepSeek、Kimi、智谱、通义选一个，注册后充几块钱。
  2. 页面「设条件 → 接口配置」里填三项：地址 https://api.deepseek.com、你的 Key、模型名 deepseek-chat（这一项默认已经填好）。
  3. 点一下「测试连接」，它会真的发一次请求，立刻告诉你通没通。
  4. 收起面板，随便粘一段群消息试，能拆开、字段也读出来了就说明通了。

填完就生效并存好了，不用点任何按钮。Key 只存在这台设备的浏览器里，不上传。换手机或换电脑时，点「复制配置」把那段文字复制走，到新设备点「粘贴配置」贴进去，不用重填。

填了 Key 却没反应？多半是漏了一项
地址、Key、模型名三项齐全才会生效，少一项就一个请求都不会发。漏的那项会在「接口配置」最底下写明。点「测试连接」能直接确认。

不想在页面上填、或者只想让电脑后台用，也可以照老办法：把 config.example.json 复制成 config.json，填好 api_key，重启监听程序。两种都配了以页面里填的为准。

出问题会怎样

没配 key、网络不通、key 失效、模型返回格式不对——都会提示原因，然后退回规则的结果，不影响你正常用。AI 是主力，但不是必需品。

隐私和成本，自己权衡
开启之后，你粘贴的整段文字会发给模型厂商（要它判断边界就得看到全文）。不开就完全不联网，所有解析都在本机完成。费用上用便宜模型每段几分钱，一天几十单一个月也就几块钱。

07用地图算真实通勤（可选）

默认的距离算法是「区 → 分钟」查表：你在设置里填「海淀 25、朝阳 45」，单子提到海淀就按 25 分钟算。粗，但可控。

问题在于粒度只到区。同样在朝阳，望京和国贸能差四十分钟。想更准就接高德地图：你填一次出发点，单子里的地点由高德转成坐标，按公交路线取真实时长，距离维度和净时薪都跟着重算。

什么时候值得开

  • 单子经常写到具体地点，比如「人大附中旁边」「望京 SOHO」「某某小区」
  • 你跨区接单，区一级的估算误差太大
  • 懒得维护「区域 → 分钟」那张表

反过来，如果你只在固定的几个小区接单，手填反而更省事——那条路线你自己走过一遍，比任何算法都准。

怎么配

  1. 打开 lbs.amap.com（高德开放平台），注册并完成个人开发者认证。
  2. 进控制台，创建一个应用，名字随便起。
  3. 给这个应用添加一个 Key，服务平台选「Web 服务」，提交。
  4. 复制生成的那串 Key。
  5. 粘到页面「设条件 → 接口配置 → 高德 Key」里，收起面板就生效；也可以填进 config.json 的 amap_key 再重启监听程序。

然后回到「设条件 → 在哪教」里填我的出发点——学校、宿舍、常去的自习室、地铁站都行，高德认得的地名就行。

Key 类型别选错
高德的 Key 分好几类。这里必须是「Web 服务」，选成「Web 端 (JS API)」调不通。如果创建时被要求填域名白名单，那是 JS API 的规矩，说明类型选错了，退回去重建一个。

结果会怎么显示

查到之后，匹配度下面会多一条：「高德查过：到人大附中 公交 34 分钟（约 8.1 公里），已按这个重算」。距离维度后面也会标上「（高德实测·公交）」，跟手填的结果一眼能分开。

「到 XX」那一截就是高德把地址理解成了哪个地方。它和单子上写的对不上，说明地址那一行取偏了，分钟数也就不可信——看到离谱的数字先对一眼这个。

地址是怎么认的

页面只采信两种行，其余一概跳过：

  • 明确标了地址的：【地址】、[地址]:、上课地点：…、学员地址：…。中英文方括号都认
  • 结尾带地名特征词的：半岛、花园、广场、小区、大厦、公寓、华庭、苑、府、湾、村、镇、路、街、号、地铁站……

带别的标签的行（[时薪]、[老师要求]、编号：）不会再被猜成地址——「编号：0517L（回）」里那个「号」曾经被当成门牌号，高德拿它搜出几十公里外的地方，通勤 90 分钟，净时薪凭空少掉 45 元。

地址写得太虚（「XX附近小区」）会被清洗成「XX附近」，高德更好定位。但这类单子下车往往还要走很远，超过 1.5 公里页面会直接提醒你：多半是终点定偏了，问清楚具体小区再算一次。

查不到会怎样

以下情况都会退回你手填的区域时间，并在页面上说明原因：没配 Key、出发点写得查不到、地点太模糊、网络或额度出问题。不会卡住，也不会编一个数糊弄你。

同一个地点只会查一次，之后再遇到直接复用结果，省额度也更快。

额度和隐私
高德给个人开发者每天有免费调用量，家教单一天几十条远远用不完；真超了也只是退回手填，不扣钱。
开了之后，单子里的地点文字会发给高德。和 AI 拆单一样，介意就别开。

08设成开机自启

默认每次开机都要手动双击一次。如果嫌麻烦，可以设成开机自动跑：

  1. 右键 启动监听.bat，选「创建快捷方式」。
  2. 按 Win + R，输入 shell:startup，回车。会打开一个启动文件夹。
  3. 把刚才那个快捷方式拖进去。

之后每次开机，程序会自动启动并打开页面。想取消就把快捷方式删掉。

小提醒
设了自启之后，每次开机都会弹一个黑色命令行窗口，属于正常现象。嫌它碍事的话可以最小化，别关。

09出问题了怎么办

双击 bat，窗口闪一下就没了
基本是没装 Python，或者装了但没加到 PATH。按第 02 节的方法验证一下。脚本里写了提示，但窗口关闭太快可能看不到——可以在文件夹里按住 Shift 右键，选「在此处打开 PowerShell 窗口」，手动敲 python clip_watch.py，就能看到具体报错。
浏览器没自动打开
看黑色窗口里打印的地址，手动复制到浏览器打开。地址是 http://127.0.0.1:8791，如果 8791 被占用会自动换成 8792、8793，以窗口里显示的为准。
页面顶部没有绿色监听条
说明页面没连上后台。两种可能：一是你双击打开的是 index.html 文件（这样是手动模式，本来就没有监听条）；二是后台没跑起来，或者端口不对。关掉页面，重新双击 bat 一次。
复制了单子，页面没反应
按顺序排查：一、微信里是不是用的「复制」而不是「转发」；二、黑色窗口还在不在；三、那条内容是不是太短、或者没有价格信息，被过滤规则挡掉了。可以手动粘进输入框试试，如果手动能分析、监听不能，多半是过滤规则的问题。
页面上的绿条变成了红字
后台断开了。通常是黑色窗口被关掉，或者程序崩了。刷新页面前先确认后台还在跑，否则刷新也连不上。
填了 config.json，AI 却一直显示未配置
先看黑色窗口里有没有一行「配置 config.json 读不出来」，有的话后面会跟具体原因，比如 Expecting ',' delimiter: line 3 column 3，意思就是第 3 行少了逗号。JSON 对格式很严格：每行末尾要有逗号（最后一行不要），字符串必须用英文双引号。最省事的办法是删掉 config.json，重新从 config.example.json 复制一份再改。
杀毒软件报警
脚本会读剪贴板、会开一个本地端口，某些安全软件会敏感。代码是纯 Python 标准库写的，六百来行，可以直接打开看。确实不放心就加白名单。

10局限，先说清楚

  • 电脑必须开着，程序必须跑着。合盖休眠、关机，监听就停。
  • 只认电脑上的剪贴板。你在手机上复制的消息，不会跑到电脑剪贴板里，工具也就看不见。唯一的例外是开了跨设备同步（见下）。
  • 它不知道你复制的是哪一条。你复制什么它就分析什么，没有“只盯某一个群”的能力——因为它压根不读群，只读你交出来的那一条。
  • 识别靠规则，不是万能的。格式特别奇怪的单子可能解析不全，比如用很少见的写法描述时间或价格。这时会显示「未说明」，你可以手动补看一眼。
  • 不会开机自启，需要按第 08 节手动设一次。
一个可以叠加的小技巧
如果你也用 Android 手机，可以在手机上装「手机连接」（Phone Link）并开启跨设备复制粘贴。这样手机上复制的东西会同步到电脑剪贴板，监听程序一样能捕获。延迟通常一两秒，够用但不稳定，适合当补充，不适合当主力。
手机上也能用，只是要手动粘
页面本身是独立的，不依赖后台。把它放到 GitHub Pages 后，手机浏览器访问同一个地址，长按复制单子、切过去点「从剪贴板读取并分析」，打分和话术一样出。AI 和高德在页面「接口配置」里填一次也能用。唯一的区别是没有「复制就自动弹结果」。

11边界

它不做的事

  • 不碰微信协议。不用第三方登录、不 hook、不破解。所以不存在封号风险，也不会有法律问题。
  • 默认不联网。所有规则解析在本机完成，剪贴板内容不会发到任何服务器，断网也能用。只有你自己配了 AI 或高德、并且真的用它拆了单或算过路，才会把这段文字或地点发出去。
  • 不保存历史。关掉页面，这一单的分析就没了。你的接单条件只存在浏览器本地存储里。

需要你自己注意的

  • 分析结果里会出现学生年级、科目、家长报价。截图发给别人之前，留意别把家长的原话带出去。
  • 群里的信息是别人发的，转述给第三方之前想一下是否合适。
