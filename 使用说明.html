01它是怎么工作的

整个工具由三个文件组成，都在同一个文件夹里（仓库里还带了 README、测试和其他文档，不影响运行）：

文件作用
启动监听.bat双击它就能跑起来，会自动找电脑上的 Python
clip_watch.py后台程序，每 0.4 秒看一眼剪贴板有没有新内容
index.html页面本体，所有分析都在这里完成
config.example.jsonAI 补全的配置模板，不用 AI 就放着别管

流程是这样的：你在微信里复制一条单子 → 后台程序发现剪贴板变了 → 判断这像不像家教需求 → 像的话推给页面 → 页面拿它跟你的条件逐项比对 → 出结果。

关键理解
工具不会去读微信。它读的是你的剪贴板——你复制了什么，它才看到什么。这是它能做到零风险的原因，也是它唯一的边界。

02装之前先确认两件事

第一件：电脑上有 Python 3

不确定的话，按 Win + R，输入 cmd 回车，在黑窗口里敲 python --version。

  • 显示 Python 3.x.x → 有了，跳过这步。
  • 提示“不是内部或外部命令” → 没装。去 python.org 下载安装，安装时务必勾上 “Add Python to PATH”，否则启动脚本找不到。

如果你装过 Anaconda，那已经自带 Python，不用再装。启动脚本会优先用它。

第二件：把文件夹放在固定位置

别放在下载目录或临时文件夹里。建议放 D:\接单工具\ 这种路径简单的地方。路径里最好不要有空格和特殊符号，避免启动脚本出问题。

03安装与启动

  1. 双击 启动监听.bat。
  2. 会弹出一个黑色的命令行窗口，显示「接单监听 已启动」和一行地址，类似 http://127.0.0.1:8791。
  3. 浏览器会自动打开这个地址。页面顶部出现一条绿色的「监听中」，前面有个闪动的小圆点，说明连上了。
  4. 把这个浏览器窗口拖到屏幕一侧，宽度缩到一半左右也行，内容会自动适应。
那个黑色窗口别关
它是程序本体。关掉监听就停了，页面上的绿条会变成红色提示断开。想停止用 Ctrl + C，或者直接关窗口。

04日常怎么用

基本流程

在微信里长按那条家教消息，选「复制」。页面会在半秒内自己跳出结果，不需要你切回去点任何东西。

一次复制多条

微信里可以多选消息后一起复制。粘进去之后，页面会自动判断：如果每一行都像一条独立的需求，就拆开分析，并按匹配度从高到低排序；如果只是同一条消息里的换行，会当成一条处理，不会拆错。

排序之后点任意一条，可以看它的详细分析。

它不会乱跳

复制普通文字（比如一段聊天、一个链接、一句工作安排），页面不会反应。只有同时满足三个条件才算家教单：长度够、命中两个以上特征词（年级、科目、老师、课时等）、并且带价格线索（元、块、课时费、时薪）。

手动模式

如果只是想临时算一单，不用开监听。直接双击 index.html 用浏览器打开，把内容粘进输入框，点「分析输入框里的内容」就行。也可以点「从剪贴板读取并分析」，一键读当前剪贴板。

05结果怎么看

结果页从上到下分四块：

区块看什么
匹配度百分制总分加结论。85 以上是「高度匹配」，70 以上「值得聊」，50 以下「不建议接」
六个维度科目、年级、课时费、距离、时间、要求，逐项打分并写一句为什么
钱和时间每周收入、净时薪、每周路上多少小时、月净收入
话术抢单开场、谈课时费、约试课，各一段，点右上角直接复制
最该看的是净时薪
「200 元一小时」听起来不错，但如果单程 40 分钟、每周两次，扣掉路上时间和车费，实际净时薪可能只有 115。这个数字才是你真正在赚的钱，也是这个工具存在的意义。

第一次用之前记得点右上角「设条件」，把你的科目、年级、常去区域和通勤时间、净时薪底线填一遍。这些存在浏览器本地，填一次就够了。

区域那条最关键，格式是 海淀:25, 朝阳:45，直接决定距离这一项算得准不准。没配的区域会被标成「距离未知」。

06开启 AI 补全（可选）

规则解析只认常见写法。有些单子写得很随意，比如「孩子高二数学老是七十多分，一周来两次，价格好商量」——「来两次」这种说法规则认不出频次，单次时长和价格干脆没写。这些空着的字段，可以让 AI 补上。

它是怎么工作的

规则先跑，一秒内出结果，该显示的立刻显示。然后如果发现关键字段缺失，才在后台调一次 AI，拿到结果后补上并重算匹配度。所以速度不受影响，AI 只负责填空，不会改掉规则已经认出来的内容。

怎么配

  1. 去模型厂商那边申请一个 API Key，DeepSeek、Kimi、智谱、通义选一个，注册后充几块钱。
  2. 在工具文件夹里，把 config.example.json 复制一份，改名为 config.json。
  3. 用记事本打开，把 api_key 那一行的值换成你申请到的 key。
  4. 保存，重启监听程序。黑色窗口里会多一行「AI 已开启」。

常见厂商怎么填

厂商base_urlmodel

结果里会怎么显示

补全成功时，匹配度下面会出现一行提示：「AI 补全了：频次、课时费」，告诉你哪些字段是它补的。如果它顺带读到了别的东西，比如「家长说孩子抵触补课」，会单独列在「AI 读到的额外信息」里。

没配 key、网络不通、key 失效，都会在同一个位置显示原因，然后退回纯规则结果，不影响你正常用。

隐私和成本，自己权衡
开启之后，单子原文会发给模型厂商。不开就完全不联网，所有解析都在本机完成。费用上用便宜模型每单几分钱，一天几十单一个月也就几块钱。

07设成开机自启

默认每次开机都要手动双击一次。如果嫌麻烦，可以设成开机自动跑：

  1. 右键 启动监听.bat，选「创建快捷方式」。
  2. 按 Win + R，输入 shell:startup，回车。会打开一个启动文件夹。
  3. 把刚才那个快捷方式拖进去。

之后每次开机，程序会自动启动并打开页面。想取消就把快捷方式删掉。

小提醒
设了自启之后，每次开机都会弹一个黑色命令行窗口，属于正常现象。嫌它碍事的话可以最小化，别关。

08出问题了怎么办

双击 bat，窗口闪一下就没了
基本是没装 Python，或者装了但没加到 PATH。按第 02 节的方法验证一下。脚本里写了提示，但窗口关闭太快可能看不到——可以在文件夹里按住 Shift 右键，选「在此处打开 PowerShell 窗口」，手动敲 python clip_watch.py，就能看到具体报错。
浏览器没自动打开
看黑色窗口里打印的地址，手动复制到浏览器打开。地址是 http://127.0.0.1:8791，如果 8791 被占用会自动换成 8792、8793，以窗口里显示的为准。
页面顶部没有绿色监听条
说明页面没连上后台。两种可能：一是你双击打开的是 index.html 文件（这样是手动模式，本来就没有监听条）；二是后台没跑起来，或者端口不对。关掉页面，重新双击 bat 一次。
复制了单子，页面没反应
按顺序排查：一、微信里是不是用的「复制」而不是「转发」；二、黑色窗口还在不在；三、那条内容是不是太短、或者没有价格信息，被过滤规则挡掉了。可以手动粘进输入框试试，如果手动能分析、监听不能，多半是过滤规则的问题。
页面上的绿条变成了红字
后台断开了。通常是黑色窗口被关掉，或者程序崩了。刷新页面前先确认后台还在跑，否则刷新也连不上。
杀毒软件报警
脚本会读剪贴板、会开一个本地端口，某些安全软件会敏感。代码是纯 Python 标准库写的，不到 200 行，可以直接打开看。确实不放心就加白名单。

09局限，先说清楚

  • 电脑必须开着，程序必须跑着。合盖休眠、关机，监听就停。
  • 只认电脑上的剪贴板。你在手机上复制的消息，不会跑到电脑剪贴板里，工具也就看不见。唯一的例外是开了跨设备同步（见下）。
  • 它不知道你复制的是哪一条。你复制什么它就分析什么，没有“只盯某一个群”的能力——因为它压根不读群，只读你交出来的那一条。
  • 识别靠规则，不是万能的。格式特别奇怪的单子可能解析不全，比如用很少见的写法描述时间或价格。这时会显示「未说明」，你可以手动补看一眼。
  • 不会开机自启，需要按第 06 节手动设一次。
一个可以叠加的小技巧
如果你也用 Android 手机，可以在手机上装「手机连接」（Phone Link）并开启跨设备复制粘贴。这样手机上复制的东西会同步到电脑剪贴板，监听程序一样能捕获。延迟通常一两秒，够用但不稳定，适合当补充，不适合当主力。

10边界

它不做的事

  • 不碰微信协议。不用第三方登录、不 hook、不破解。所以不存在封号风险，也不会有法律问题。
  • 不联网。所有分析在本机完成，剪贴板内容不会发送到任何服务器。断网也能正常用。
  • 不保存历史。关掉页面，这一单的分析就没了。你的接单条件只存在浏览器本地存储里。

需要你自己注意的

  • 分析结果里会出现学生年级、科目、家长报价。截图发给别人之前，留意别把家长的原话带出去。
  • 群里的信息是别人发的，转述给第三方之前想一下是否合适。
